## [yoCrypt-Editor](https://yoyo-ace1110.github.io/yoCrypt-Editor/zh-TW/home)
# 操作指南

yoCrypt-Editor 的設計核心在於「透明的加密體驗」。以下是 **File (檔案)** 選單中各項功能的詳細說明: 

## 📂 檔案開啟與儲存
編輯器會根據您的需求，處理加密與未加密檔案。

- **開啟未加密文件 (Open, `Ctrl+Shift+O`)**: 開啟標準純文字檔案。
- **開啟加密文件 (Open Crypted, `Ctrl+O`)**: 開啟受 AES-256 保護的檔案。開啟時系統會要求輸入正確的主密碼。
- **儲存文件 (Save / Save As)**: 以未加密的純文字格式儲存或另存新檔。
- **儲存加密文件 (Save Crypted / Save Crypted As)**: 將當前內容以 AES-256 加密格式儲存。若尚未驗證密碼，系統將提示輸入。
- **自動儲存 (Auto Save, `Ctrl+S`)**: **最推薦的儲存方式**。系統會根據該檔案開啟時的狀態自動判定: 
    - 若開啟時是加密檔，則自動用原密碼加密存回。
    - 若開啟時是普通文件，則以純文字存回（預設不加密）。

## 🔐 密鑰管理
- **變更主密碼 (Change Master Password)**: 
    這是本專案的核心維護功能。執行後，系統會要求輸入新密碼，並自動將 **「本專案/Files」資料夾下** 的所有加密文件全數解密，隨即使用新密鑰重新加密，確保所有存檔的一致性。
